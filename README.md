# Aurora Borealis Sighting Observation Log
オーロラ目撃記録（日時・場所・Kpインデックス・色・強度）を管理するObservationログ帳。
## Features
- 日時・場所・Kpインデックス（0-9）・色（4種類）・強度（5段階星評価）・メモを記録
- 月別ヒートマップで目撃頻度を可視化
- 目撃記録の編集・削除機能
- 統計サマリ（総件数・最高Kp・平均Kp・最多観測色）
- localStorage永続化（デモデータ付きで初回から動作確認可能）
## Usage
フォームに目撃情報を入力して「Save Sighting」を押すとログに記録される。既存エントリの✏️ボタンで編集、🗑️ボタンで削除できる。
